# Frontend — ReservSlot

Aplicación Angular 21 (standalone) del proyecto ReservSlot.

```bash
npm install
npm start
```

La configuración de la API está en `src/environments/`. En desarrollo apunta a
`http://localhost:8080`; en producción usa rutas relativas `/api` y `/public`.

Consulta el [README principal](../README.md) para la puesta en marcha completa y
[`deploy/README.md`](../deploy/README.md) para el despliegue.
